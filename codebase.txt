CI STAGE ORDER (npm run test:ci, fail fast)
  harness (verify-harness) -> lint -> spec -> format -> syntax -> unit -> cross-module -> e2e -> api -> regression

DEFAULT MODULE CONTRACT (names are defaults. If you change one, update this file and docs/decisions.md)
  util/rng.ts          mulberry32(seed), createRng(seed): { next(), int(a,b), pick(list), fork(label) }
                       Two streams: sim (gameplay) and cosmetic (particles, noise buffers). Math.random is banned.
  app/clock.ts         Clock { nowMs() }. Real and fake implementations. Only file allowed to read real time.
  sim/types.ts         InputState { moveX, moveY, jump, action } with moveX and moveY in [-1, 1]
                       GameEvent union (hit, jump, splash, laser, timeFieldEnter, timeFieldExit, spawn, defeat, ui)
  sim/world.ts         createWorld(seed), step(world, input, fixedDt), world.events drained each frame, hashWorld(world)
  assets/loader.ts     loadManifest(), loadImages(manifest), parseManifest(unknown)
  assets/animation.ts  sampleAnimation(manifest, characterId, name, elapsedMs) -> { spriteId, dx, dy, rot, sx, sy, alpha }
                       resolves aliases, interpolates keyframes, pure
  render/viewport.ts   pickPreset(winW, winH), computeLayout(win, preset), applyLayout(canvas, layout)
  render/renderer.ts   render(ctx, world, atlas, alpha)
  audio/port.ts        AudioPort { unlock(), play(cue), setMuted(bool) }  Cues map from GameEvents in app/
  input/input.ts       createInput(target): { poll(): InputState, dispose() }
  app/test-hooks.ts    exposes window.__cosmic (read-only snapshot: tick, seed, timeScale, entities) only when the URL has ?test=1

WHERE DOES X GO
  New enemy behavior                 -> src/sim/ and its test in tests/unit/
  New sound                          -> src/audio/voices/ as a data spec, plus a spec test
  New sprite pose or image           -> a human adds the file, runs npm run assets:lock, then edits assets.json
  Screen layout, letterboxing        -> src/render/viewport.ts
  Button or HUD element              -> src/ui/ (touch D-pad lives in src/input/)
  Anything that needs real time      -> src/app/clock.ts only
  Anything that needs fetch          -> src/assets/loader.ts only
  A new dependency                   -> do not. Ask the human, then edit tech-stack.json and package.json together
